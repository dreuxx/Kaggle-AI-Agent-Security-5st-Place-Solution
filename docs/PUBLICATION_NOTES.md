## What was preserved

## Artifact availability update

When the article was originally prepared, its editor had Markdown records but not the archived JSON bytes. The later repository upload supplies those bytes. This release now includes 24 selected artifacts and checks the central figure means and EOG diagnostics directly against them. No model replay or private evaluation was performed.

Statements in the unchanged article/PDF about JSONs not being included describe the original editorial package. For current availability, use `experiments/README.md` and `experiments/artifact_manifest.json`. The selected artifacts’ replay rows, messages, tool events, and diagnostic observations remain unchanged.

## Privacy transformations

Personal home-directory paths are replaced with neutral local-path placeholders. The original and published SHA-256 values are both retained in manifests. Historical hashes within experimental records were not rewritten to pretend that a sanitized file is the original byte stream. No Kaggle credential from the conversation was copied or used.

Known credential-pattern checks cover Kaggle, GitHub, AWS-style access keys, common API-token formats, and private-key headers. These checks are a bounded publication screen, not a guarantee that every possible secret format can be detected. A credential-like fixture match occurred in the omitted SDK tree; it was not copied into the public repository.

## What stays out of the main Git repository

The installed SDK/evaluator snapshot, its dependency wheel, model files, environment files, credentials, and the full exploratory output directory are not vendored. The SDK’s original license notice is retained without applying it to the author’s work.

The optional research archive contains historical first-party files and outputs with local paths sanitized. Two private-gateway diagnostic files are withheld from that archive because their release provenance and relevance were not established; the untouched original ZIP remains the full backup. The archive is a historical record, not a supported replay environment.

## Tests and licenses

New tests validate publication integrity only. No claim is made that the original historical test suite passes against the present source. No open-source license has been chosen on the author’s behalf; `LICENSE.md` records that decision explicitly.

The release was assembled locally. Nothing was committed, pushed, uploaded to GitHub, or submitted to Kaggle.
